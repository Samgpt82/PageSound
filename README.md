# Summeries & Sound - Book Summaries & Podcasts Website

A modern, data-driven website for sharing book summaries and podcast episodes.

## Adding New Books

To add a new book, simply edit `data/books.json` and add a new entry:

```json
{
  "id": "book-slug",
  "title": "Book Title",
  "author": "Author Name",
  "category": "Category",
  "coverImage": "https://...",
  "coverImageThumb": "https://...",
  "description": "Short description",
  "summary": "Full summary text",
  "keyTakeaways": ["Takeaway 1", "Takeaway 2", "Takeaway 3"],
  "audioFile": "path/to/audio.mp3",
  "audioDownloadName": "book-title-summary.mp3",
  "scriptFile": "path/to/script.pdf",
  "releaseDate": "Month Year",
  "dateAdded": "YYYY-MM-DD",
  "summaryLength": "X words"
}
```

**Note:** `scriptFile` is optional. If provided, a "View script/transcript" link will appear next to the download link on the book detail page.

Then create a folder: `books/[book-id]/` and copy `books/template.html` to `books/[book-id]/index.html`.

## Adding New Podcasts

To add a new podcast, edit `data/podcasts.json` and add a new entry:

```json
{
  "id": "podcast-slug",
  "title": "Episode Title",
  "episodeNumber": 13,
  "length": "20 min",
  "coverImage": "https://...",
  "coverImageThumb": "https://...",
  "description": "Short description",
  "summary": "Full episode summary",
  "highlights": ["Highlight 1", "Highlight 2", "Highlight 3"],
  "audioFile": "path/to/audio.mp3",
  "audioDownloadName": "episode-title.mp3",
  "scriptFile": "path/to/script.pdf",
  "format": "Format type",
  "releaseDate": "Month Day, Year",
  "dateAdded": "YYYY-MM-DD"
}
```

**Note:** `scriptFile` is optional. If provided, a "View script/transcript" link will appear next to the download link on the podcast detail page.

Then create a folder: `podcasts/[podcast-id]/` and copy `podcasts/template.html` to `podcasts/[podcast-id]/index.html`.

## File Structure

```
/
├── data/
│   ├── books.json          # All book data
│   └── podcasts.json       # All podcast data
├── books/
│   ├── [book-id]/
│   │   └── index.html      # Individual book pages (auto-generated from JSON)
│   ├── index.html          # All books listing
│   └── template.html       # Template for new book pages
├── podcasts/
│   ├── [podcast-id]/
│   │   └── index.html      # Individual podcast pages (auto-generated from JSON)
│   ├── index.html          # All podcasts listing
│   └── template.html       # Template for new podcast pages
├── scripts/
│   ├── render-books.js     # JavaScript to render books dynamically
│   ├── render-podcasts.js  # JavaScript to render podcasts dynamically
│   ├── subscribe.js        # Email subscription handler
│   └── download.js         # Audio download handler
├── members/
│   └── subscribers.csv     # Email subscribers (generated by server)
├── index.html              # Homepage
├── about/
│   └── index.html          # About page
├── contact/
│   └── index.html          # Contact page
└── styles.css              # Global styles
```

## Running Locally

1. For static hosting (GitHub Pages, etc.):
   - Just open `index.html` in a browser or use a simple HTTP server
   - Note: Email subscription won't work without a backend

2. For full functionality (with email subscription):
   - Install Node.js dependencies: `npm install express`
   - Run the server: `node server.js`
   - Visit: `http://localhost:3000`

## Deployment

- **Static hosting**: Upload all files to GitHub Pages, Netlify, or similar
- **With backend**: Deploy `server.js` to Render, Railway, or similar Node.js hosting
